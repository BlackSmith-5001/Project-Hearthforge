スマホへの追加方法

この教材はPWAです。ただし、PWAはHTMLファイルを直接開くだけではインストールできません。HTTPSで公開されたURLをAndroidのChromeで開いてください。

GitHub Pagesで公開する場合

  1. genai-passportフォルダの中身を、自分のGitHubリポジトリへアップロードします。
  2. GitHubのSettings → Pagesで、公開元に対象branchとフォルダを指定します。
  3. 発行されたhttps://のURLをAndroidのChromeで開きます。
  4. 画面上の「ホーム画面に追加」を押すか、Chromeのメニューから「アプリをインストール」を選びます。

大事な注意

  • 最初に一度、オンラインでページを開いてください。
  • その後は教材本体、図、確認問題、進捗記録をオフラインで使えます。
  • 公式シラバスや試験情報を見るときはインターネットが必要です。
  • 試験そのものは、公式の受験環境・禁止事項に従ってください。
